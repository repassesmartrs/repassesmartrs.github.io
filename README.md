# Repasse Smart RS · Atacado para lojistas

Site público do catálogo de atacado: https://repassesmartrs.github.io

Preços (`dados.json`) e fotos atualizados todo dia pela rotina automática do catálogo interno, com as margens de atacado da aba "Tributos e margens". Regras: pedido mínimo, pagamento só por PIX e envio a combinar com o vendedor.
